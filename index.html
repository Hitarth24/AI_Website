AI-Powered Retail Analytics Using Object Detection

Leveraging state-of-the-art object detection models to automate retail shelf monitoring, cart analysis, and store foot-traffic insights by combining YOLOv8 and YOLO-NAS pipelines to deliver real-time, data-driven visibility

Blog

MOTIVATION Shopping in a modern grocery store appears seamless to customers: they walk in, pick up what they need, and leave-rarely considering the operational complexity behind the scenes. However, for store managers and retail teams, maintaining profitability and efficiency requires far more than simply tracking sales. Critical business insights like customer behavior patterns, product trends, and anomalies-are often hidden and difficult to extract using traditional methods which is what we plan to tackle.

Currently, marketing teams and store managers rely heavily on outdated approaches like manual surveys, in-person observations, and guesswork. These methods are labor-intensive, slow, and often fail to capture the nuanced realities of in-store activity and also, most basic vision models do not work very well on these applications due to complex video footage and the randomness in these videos and images. In particular, what customers place in their carts represents a rich, underutilized source of behavioral data that could drive smarter inventory management, targeted promotions, and improved store layouts. Furthermore analyzing the popular hot spots of the store and what items get picked the most from the shelves also contains this valuable information.

Our solution bridges this gap: by deploying AI-powered, real-time cart, shelf, and store monitoring, we aim to deliver actionable insights and immediate visibility into customer interactions. This approach empowers retailers to move beyond reactive, manual processes and embrace data-driven decision-making that enhances both operational efficiency and the overall shopping experience.

EXPERIMENTAL SETUP


  1. Cart Detection
    Detecting items in shopping carts using computer vision is one of the first ways we made retail better. We used object detection to identify products placed in shopping carts from retail store images. The entire pipeline was built using Google Colab with GPU acceleration and Python 3 for efficient training. We used SuperGradients framework for training object detection models and. Our dataset is sourced from Roboflow and contains annotated images with YOLO-format bounding boxes for 27 object classes such as Apples, Milk, and Water Bottles, including carts when labeled. To improve the model’s robustness and generalization, we applied data augmentations like random affine transformations, translation, scaling, and shearing. This enables accurate detection of items within shopping carts for automated inventory tracking.


  2. Shelf Detection
    For this objective, we worked within the Google Colab environment using Python 3 and PyTorch, with GPU acceleration enabled when available. The dataset for this part was structured to follow the YOLOv8 format, including a data.yaml file that specified training, validation, and test splits, class names, and class count. This dataset contained 55 new classes along with training, validation and test data to detect and classify these objects. We chose to train on the YOLOv8m model from the Ultralytics suite due to its solid trade-off between speed and accuracy, especially suitable for object detection tasks in retail environments. The training was configured with 50 epochs, a batch size of 16, and an image size of 640x640. Hyperparameters such as learning rate, momentum, and weight decay were tuned to optimize convergence, and early stopping was introduced for 10 epochs to prevent overfitting. All output logs, metrics, checkpoints, and annotated results were organized and stored in a dedicated results directory on Google Drive for tracking throughout the project lifecycle.


  3. Store-Foot Analyzer
    The experimental setup for this objective was implemented within the Google Colab environment, utilizing Python 3 and the PyTorch framework, with GPU acceleration enabled to expedite training. The dataset was reformatted to align with the YOLOv8 standard along with class labels and total class count. This custom dataset comprised 55 novel object whilst recognizing person class objects as well relevant to retail scenarios, each annotated for detection and classification tasks. We selected the YOLOv8m architecture from the Ultralytics model suite, as it offers a balanced compromise between computational efficiency and detection accuracy, making it particularly effective for real-time analysis in retail settings. Training was conducted over 50 epochs with a batch size of 16 and an input resolution of 640×640 pixels. Key hyperparameters, including learning rate, momentum, and weight decay, were fine-tuned to enhance convergence stability. To mitigate overfitting, an early stopping mechanism with a patience threshold of 10 epochs was applied. All training artifacts such as loss metrics, specifically, mAP and IDSWs, were systematically stored.

METHOD

  1. Cart Detection
    • First, we selected YOLO-NAS (You Only Look Once- Neural Architecture Search) for object detection in retail store images, due to its strong balance of speed and accuracy.
    • Then, we implemented the pipeline using the SuperGradients library and began with environment setup, installing essential dependencies such as: Super-gradients, Imutils, Roboflow, Compatible PyTorch packages
    • Next, we loaded our annotated dataset using SuperGradients COCO-format dataloaders, which allowed seamless splitting into training, validation, and test sets.
    • To improve model generalization, we applied and visualized data augmentation techniques, making sure the transformations preserved label accuracy and increased image diversity.
    • During training, we fine-tuned YOLO-NAS using: PPYoloELoss as the loss function, DetectionMetrics_050 for performance evaluation, Post-processing callbacks to refine outputs
    • We incorporated checkpointing and experiment tracking to ensure consistent and reproducible results.
    • Finally, we evaluated the model's performance using mean Average Precision (mAP) and conducted visual inspections of detection outputs to confirm real-world effectiveness.



  2. Shelf Detection
    • First, we loaded and organized the custom dataset with 55 classes, setting up the folder structure and labels for seamless model training and evaluation.
    • We used YOLOv8's built-in augmentation features and applied techniques like mosaic, mixup, rotation, flipping, HSV color shifts, and scaling. This process helps the model generalize better on different shelf conditions other than pre-trained dataset.
    • Once the augmentations were set, we trained and fine-tuned the model on our dataset, adjusting hyperparameters along the way to balance speed and accuracy.
    • After training, we validated the model using key performance metrics: precision, recall, mAP@0.5, mAP@0.5:0.95, and F1-score. This was done for both overall and per class so we could really see where the model performed well or struggled.
    • We visualized the training performance by plotting loss and metric curves across epochs to spot overfitting or convergence issues.
    • For the testing part, we ran inference on all test images, collected class-wise detection counts, and created bar charts and confidence histograms to analyze detection frequency and prediction certainty.
    • Finally, we built a comparison module that takes two shelf images (before and after), runs object detection on both, and compares the product counts; helping us figure out which items were sold or restocked between the two snapshots.



  3. Store-Foot Analyzer
    • Each video frame is processed by the YOLOv8 object detection model, which generates bounding boxes and associated confidence scores.
    • The tracking pipeline first matches high-confidence detections with active trajectories using spatial and appearance-based matching.
    • Any unmatched tracks are then compared against low-confidence detections to recover possible missed matches.
    • Each detected person is assigned a globally consistent ID that remains the same across all frames and this ID-based tracking allows the system to maintain identity continuity over time and across movement.
    • The tracking data enables analysis of individual movement between predefined store zones and the collected information supports behavior analytics, identifying patterns in customer interactions.
    • Occupancy heatmaps are generated to visualize which areas of the store receive the most foot traffic.
    • The system also models real-time customer flow, helping optimize store layout and operational efficiency.
